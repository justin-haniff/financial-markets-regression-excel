# Financial Markets Regression Analysis (Excel)

## Overview
This project analyzes historical stock return data to evaluate how individual firm returns move relative to the broader market.

## Data
- Daily price data for selected publicly traded firms
- S&P 500 index used as the market benchmark

## Methods
- Calculated daily returns using Excel formulas
- Conducted regression analysis of stock returns on market returns
- Organized model into separate sheets for raw data, returns, regression output, and summary

## Key Insight
The regression results indicate that each stock’s returns are positively related to market returns, with differing sensitivities that reflect variation in market exposure and systematic risk.
